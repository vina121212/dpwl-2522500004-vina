# pertemuan-01
1. kesinambungan PWD–DPW–DPWL;
keterhubungan dan keberlanjutan data, proses, serta informasi antara tingkat PWD, DPW, dan DPWL, sehingga informasi dapat mengalir secara konsisten dari satu tingkat ke tingkat lainnya tanpa terjadi duplikasi, kehilangan, atau ketidaksesuaian data.
2. perbedaan PHP terstruktur dan MVC;
Perbedaan utama antara PHP terstruktur dan MVC terletak pada cara pengaturan dan pemisahan kode.PHP terstruktur menggabungkan logika bisnis, koneksi database, dan tampilan HTML dalam satu file yang sama secara berurutan.MVC memisahkan aplikasi menjadi tiga komponen terpisah: Model (data/database), View (tampilan antarmuka), dan Controller (penghubung logika).
3. fungsi Model, View, dan Controller;
Fungsi ModelMengelola data dan logika bisnis aplikasi.
Fungsi ViewMenyajikan informasi atau antarmuka pengguna (Graphical User Interface / GUI).
Fungsi ControllerMenjadi penghubung atau penjembatani antara Model dan View.
Model, View, dan Controller (MVC) adalah pola arsitektur yang memisahkan aplikasi menjadi tiga komponen utama agar kode lebih terstruktur, mudah dikembangkan, dan dirawat.
4. alur request–response MVC;
Alur request-response pada arsitektur MVC (Model-View-Controller) dimulai saat pengguna mengirim permintaan (request) melalui browser dan berakhir ketika aplikasi mengirimkan tampilan atau data kembali (response)
5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan;
Pemetaan Fitur Aplikasi DPW ke Model, Controller, dan View
Dalam pengembangan aplikasi DPW, konsep MVC (Model–View–Controller) digunakan untuk memisahkan pengelolaan data, proses aplikasi, dan tampilan. Dengan pemisahan ini, aplikasi menjadi lebih terstruktur dan mudah dikembangkan. Pemetaan ini membuat pengelolaan kegiatan lebih terorganisasi. Model hanya berfokus pada data, Controller menangani proses, sedangkan View berfokus pada interaksi dengan pengguna.
6. kesimpulan P1;
Kesinambungan PWD–DPW–DPWL penting untuk menjaga data dan informasi tetap terhubung dan terintegrasi. PHP terstruktur berbeda dengan MVC karena MVC memisahkan program menjadi Model, View, dan Controller sehingga lebih rapi dan mudah dikembangkan. Model mengelola data, View menampilkan informasi, dan Controller mengatur proses serta hubungan keduanya. Alur MVC dimulai dari request pengguna → Controller → Model → View → response. Pada aplikasi DPW, pembagian ini dapat diterapkan pada fitur seperti data anggota, kegiatan, dan pertemuan agar sistem lebih terstruktur, mudah dikelola, dan dipelihara.
